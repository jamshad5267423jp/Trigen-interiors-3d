# Trigen Interiors — 3D GitHub Pages Website

A standalone, lightweight 3D-style showroom website for Trigen Interiors.

## Files

- `index.html` — complete page structure/content
- `style.css` — responsive premium showroom styling
- `script.js` — gallery, filters, animations and Three.js 3D showroom
- `assets/trigen-logo.webp` — the exact logo supplied in the conversation

## GitHub Pages

1. Create a new public repository, e.g. `trigen-interiors-3d`.
2. Upload these files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the free `github.io` URL.

## Important

The showroom images currently use public Unsplash image CDN URLs so the repository stays small. For the final production website, replace these image URLs with Trigen's own project/product photos. This will make the website more authentic and avoids depending on an external image CDN.

Three.js is loaded from cdnjs. The website remains a static site and does not require a server or database.
